## 👨‍💻 About Me

I'm **Aakaash Mathew**, a Software Test Engineer working across manual, automation and API testing of web applications.

I build **Playwright (TypeScript)** and **Cucumber BDD** frameworks using the Page Object Model, cross-browser coverage and reusable utilities. I also have working knowledge of **Selenium WebDriver with Java and TestNG**. I work in Agile/Scrum teams, track defects in Jira, test APIs with Postman, and validate backend data with SQL.

I enjoy turning requirements into BDD scenarios, replacing repetitive manual checks with maintainable automated tests, and investigating failures until the root cause is clear.

## 🧠 My Testing Philosophy

<table>
<tr>
<td width="50%" valign="top">

### 🎯 Quality First

- Understand requirements before testing.
- Convert requirements into clear BDD scenarios.
- Cover positive and negative scenarios.
- Validate edge cases and error handling.

</td>
<td width="50%" valign="top">

### ⚙️ Automation First

- Prefer stable, maintainable locators.
- Use reusable Page Objects, steps and utilities.
- Rely on auto-waiting instead of hard sleeps.
- Reduce flaky tests and duplication.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🔍 Debugging & Analysis

- Investigate failures systematically.
- Use traces, screenshots and network interception.
- Identify reproducible defects.
- Document clear steps to reproduce in Jira.

</td>
<td width="50%" valign="top">

### 🚀 Continuous Improvement

- Organize suites with tags (smoke, sanity, regression).
- Run across Chromium, Firefox and WebKit.
- Review reports and failure patterns.
- Keep learning better testing practices.

</td>
</tr>
</table>

## 🔄 Automation & CI/CD

My goal is to make automated testing repeatable, observable and easy to maintain. I'm also interested in **DevOps**, and I'm keen to learn more about how pipelines, builds and releases fit together.

```text
Code Changes
     │
     ▼
Git Repository (GitHub / GitLab)
     │
     ▼
CI Pipeline (GitHub Actions / Jenkins)
     │
     ▼
Install Dependencies (npm / Maven)
     │
     ▼
Execute Tests (Playwright · Cucumber · TestNG)
     │
     ▼
Capture Failures & Reports (Allure · HTML · Extent)
     │
     ▼
Review Results & Log Defects (Jira)
```

**Areas of focus:**

- Automated test execution on every build
- Smoke, sanity and regression suites before each release
- Test reporting and debugging
- Reproducible test environments
- Continuous feedback on software quality
